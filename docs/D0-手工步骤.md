## 一、安装 Docker（约 60–90 分钟，可后台下载）

### 方式 A：Docker Desktop（推荐，最省事）

1. 下载：<https://www.docker.com/products/docker-desktop/>（约 600MB）
   或命令行：`winget install -e --id Docker.DockerDesktop`
2. 双击安装，安装时勾选 **Use WSL 2 instead of Hyper-V**。
3. 安装完**注销/重启**一次（WSL 集成需要）。
4. 打开 Docker Desktop → Settings → Resources → **WSL Integration** → 打开 **Ubuntu**。
5. 验证（PowerShell 或 cmd）：

```powershell
docker --version
docker compose version
docker run --rm hello-world
```

### 方式 B：WSL2 内装 Docker Engine（不装 Desktop）

```bash
wsl -d Ubuntu
sudo apt update && sudo apt install -y docker.io docker-compose-v2
sudo usermod -aG docker $USER   # 重新登录生效
docker --version && docker compose version
```

> 注意：WSL 内 Docker 需要在 Windows 侧设 `DOCKER_HOST` 才能从 PowerShell 用；日常在 WSL 里用即可。

### 必做：限制 WSL 内存（这台机器只有 7GB）

新建 `C:\Users\69561\.wslconfig`：

```ini
[wsl2]
memory=4GB
swap=2GB
processors=4
```

然后 `wsl --shutdown`，再启动 Docker。

### 预拉镜像（约 1.5GB）

```bash
docker pull postgres:16
docker pull pgvector/pgvector:pg16
```

> Redis 已从方案里砍掉，**不用拉**。

### 常见问题

| 现象 | 处理 |
|---|---|
| `docker: not found` | Docker Desktop 没启动，或 WSL 集成没开 |
| WSL 启动失败 | BIOS 开虚拟化（VT-x/AMD-V）；`wsl --update` |
| 拉镜像超时 | Docker Desktop → Settings → Resources → Proxies 填公司代理 |
| 内存不足 | 确认 `.wslconfig` 生效：`wsl --shutdown` 后重启 Docker |

## 二、填 key（约 10 分钟）

1. 复制模板：

```bash
copy .env.example .env
```

2. 编辑 `.env`，只改三行：

```ini
OPENAI_BASE_URL=https://api.deepseek.com/v1
OPENAI_API_KEY=sk-你的key
CALIPER_MODEL=deepseek-chat
```

> 任何 OpenAI 兼容端点都行（DeepSeek / 通义 / 硅基流动 / OpenRouter）。先用最便宜的模型，评测阶段再换。

3. `.env` 已在 `.gitignore` 里，不会被提交。

4. 验证（在项目根目录、已激活 venv）：

```bash
python -m caliper doctor
```

5. 打通一次真实调用：

```bash
python - <<'PY'
import os, httpx
for line in open('.env', encoding='utf-8'):
    line = line.strip()
    if line and not line.startswith('#') and '=' in line:
        k, v = line.split('=', 1); os.environ[k.strip()] = v.strip()
r = httpx.post(os.environ['OPENAI_BASE_URL'].rstrip('/') + '/chat/completions',
               headers={'Authorization': 'Bearer ' + os.environ['OPENAI_API_KEY']},
               json={'model': os.environ['CALIPER_MODEL'],
                     'messages': [{'role': 'user', 'content': 'hi'}],
                     'max_tokens': 8},
               timeout=30)
print(r.status_code, r.text[:200])
PY
```

期望：`200` + 一段 JSON。
