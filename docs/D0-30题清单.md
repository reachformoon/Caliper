# 评测任务集设计（30 题，D8 落地）

> 目标：不是刷榜，是让 gate 能对 6 个能力下判决。配额是硬约束，缺一类就补，不许拿同类凑数。

## 配额

| 类别 | 数量 | 用途 |
|---|---|---|
| 通过率判分（有 subtests） | ≥ 12 | n=30 下提升统计功效 |
| 跨文件 | ≥ 8 | 验证多文件编辑 |
| 跨工具（file + shell + MCP） | ≥ 6 | 验证 function call 与工具编排 |
| 长周期（≥20 步或 ≥10 分钟） | ≥ 4 | 验证耐久层与成本 |

## 每题字段（YAML）

```yaml
id: fix-circular-import
prompt: "..."
fixtures: fixtures/repo-a/
hidden_tests: tests-h/
test_cmd: "pytest -q tests-h"
subtests: [t_import, t_cycle, t_cli, t_api]

tags: [xfile, PR]
```

## 体检（D8 前必做）

- 空解跑一遍：**必须失败**（题没被解决）
- 参考补丁跑一遍：**必须通过**（题可解）
- 隐藏测试在运行前不可见
